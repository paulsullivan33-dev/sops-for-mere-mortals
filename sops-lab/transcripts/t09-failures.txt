# filestatus answers 'is this a sops file, and is it sealed?'

# without needing any key.

$ sops filestatus app.enc.yaml
{"encrypted":true}

$ sops filestatus plain.yaml
{"encrypted":false}

# The stranger's key: a perfectly good age key that is simply

# not a recipient of this file.

$ SOPS_AGE_KEY_FILE=/home/hatch/workspace/sops-labwork/work/keys/stranger.txt sops decrypt app.enc.yaml 2>&1 | head -3; true
Failed to get the data key required to decrypt the SOPS file.

# No key anywhere sops looks:

$ env -u SOPS_AGE_KEY_FILE -u SOPS_AGE_KEY HOME=/home/hatch/workspace/sops-labwork/work/failures/nohome sops decrypt app.enc.yaml 2>&1 | tail -3; true
Recovery failed because no master key was able to decrypt the file. In
order for SOPS to recover the file, at least one key has to be successful,
but none were.
